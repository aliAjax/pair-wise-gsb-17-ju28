# hxwl-03 岩土钻孔编录

钻孔分层、标贯与地下水位的现场记录面板

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- 新建 / 修订钻孔：编号、设计孔深、地下水位埋深
- 分层按深度从浅到深添加，层顶自动接住上一层层底，末层层底不得越过设计孔深
- 保存时校验：编号重复、水位与孔深 / 分层深度冲突、层底倒挂、岩性空缺等，
  在保存处逐条指出问题数据并保留表单内容
- 可移除单条分层或一键移除未完成分层；已有钻孔可修订、删除
- 记录保存在浏览器 localStorage，重新打开后仍可找到
- 顶部指标（累计孔深、地层数量、最高标贯、地下水位）由记录实时计算
- 左侧岩性筛选同步收窄钻孔列表，支持多选与计数
- 可导出全部记录为 JSON 摘要
