# hxwl-03 岩土钻孔编录

钻孔分层、标贯与地下水位的现场记录面板

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- 新建钻孔：编号、设计孔深、地下水位埋深（未量测可留空）
- 分层由浅到深连续编录：层顶自动接住上一层层底（首层自 0m 起），末层深度不得越过孔深，可逐层移除
- 保存校验：编号缺失/重复、孔深非法、标贯非整数、水位与分层深度冲突等问题在保存按钮上方逐条指出，表单原样保留
- 已有钻孔可修订、移除；分层未到底的钻孔标记为“未完成”，可继续补录未完成分层
- 记录保存在浏览器 localStorage，重新打开仍可找到
- 顶部指标（累计孔深、地层数量、最高标贯、最浅水位）全部由记录实时计算
- 左侧岩性筛选（黏土 / 粉砂 / 卵石 / 强风化）同步收窄钻孔列表，支持多选（任一匹配）
